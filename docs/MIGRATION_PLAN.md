# Migration Plan

This architecture is the blueprint before making major code changes.

**Do not start by rewriting the whole CPS codebase.** Instead:

1. Inspect the current project.
2. Map its existing components against the [architecture](ARCHITECTURE.md).
3. Migrate/refactor module by module.

OLD CPS

MaCoKi Clinical
